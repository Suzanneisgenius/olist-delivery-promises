# Explainer card — v0.4.1: making the release gate fail closed

**One sentence.** A page may only be published if an independent script, which imports none of the project
code, has recomputed every model metric from the raw data and the saved predictions *in the same run*, and
the browser and UAT evidence must name the exact page files they tested.

## What was wrong (found by the v0.4.0 review)
1. `run_all` went 1→2→3→4 but stage 4 read a verification file that only the verifier writes, so a refresh
   could consume an **old** verification.
2. The "all match" message only checked raw hashes and test labels; a fault injection that set logistic
   AUC and recall to 1.0 still showed "all match".
3. UAT ignored the pytest exit code and accepted old browser evidence.

## What changed
| Fix | How it works |
|---|---|
| Refresh order | stage 1 → 2 → 3 → **verify** → 4 (→ 5). Stage 3 deletes the previous verification; the verifier writes a new one only if everything matches |
| Full check | For all 3 models: n, late, AP, ROC AUC, Brier, selected, hits, precision, recall + identities precision = hits/selected, recall = hits/late |
| Binding | The verification stores SHA-256 of predictions, metrics, checks, lineage, config and the source manifest; stage 4 blocks if any changed |
| UAT | pytest must exit 0 with ≥1 test and no failure/error; skipped ≠ pass; browser evidence must hash-match the current pages; owner sign-off lives in `uat/owner_signoff.csv` and is never written by code |

## Evidence
- Live fault injection (AUC and recall → 1.0): verifier lists 3 mismatches, exits 1; stage 4 blocks; no page is written.
- Negative tests in `tests/test_stage41.py` and `tests/test_stage4.py`.

## Say it in an interview
"A check that compares a number with itself proves nothing. I made the verifier independent — separate
interpreter, no project imports — and bound every piece of evidence to file hashes, so stale or
inconsistent evidence blocks the release instead of being reported as a pass."

## Don't claim
Browser checks and automated UAT are not business sign-off; UAT-13 and UAT-14 are still the owner's.
