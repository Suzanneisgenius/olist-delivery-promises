# 阶段 3 交接（v0.3.1）

基线：上传的 v0.3.0；本轮保留原始上传文件，在本地工作副本修复并重新拟合阶段 3。
九份原始 CSV 的 SHA-256 与 Stage 1 清单一致；订单集市来自本机已经验收的 Stage 2 版本。
测试、指标复核及运行环境均记录当前实际结果，不沿用上传包的环境声明。

## 实现的协议（`config/model.yaml`）

- 预测时点：`order_purchase_timestamp`。样本：批准窗口内、最终结果 A/L、单卖家订单。U、X、多卖家订单只计数、不建模。
- 切分（按下单时间，也是标签截止）：train < 2018-01-01 ≤ dev < 2018-04-01 ≤ test。
- 标签可得：拟合和选择模型都只用当时已签收的标签。调参拟合截止 2018-01-01；
  验证集用于参数/模型家族选择时，也要求签收时间早于 2018-04-01；最终拟合截止相同。
- 卖家历史：只用在快照时点 T 之前已签收的单卖家订单；训练行 T = 下单当月月初，评估行 T = 所在评估块开始日，冻结不更新。
- 模型：常数基准、逻辑回归、HistGradientBoosting。小网格按可得验证标签的 AP 选参数和主模型；
  然后在可得的 train+dev 标签上重拟合、冻结。本轮重新评价了 v0.3.0 已看过的测试集，
  不把它称为新的确认性测试；参数和主模型仍未按测试集选取。
- 评估：AP（主）、ROC AUC、Brier、每购买周前 10%（向下取整）的精确率和召回率；按购买周重采样的 bootstrap（1,000 次）；校准分箱；置换重要性。

## 本轮发现并修复

- 原验证集 20,384 单中，有 3,807 单在测试开始时尚未签收，其中 1,496 单最终延误。
  原代码虽然挡住了未来训练标签，却用这些未来验证标签选择模型；最晚一单直到 2018-09-19 才签收。
- 模型选择现用 16,577 单、1,156 个已知延误标签，延误率 6.97%。逻辑回归 C=0.1 的验证 AP
  从上传报告的 0.274 改为本轮 0.139。两次 AP 的评价样本不同，不能说它代表相同总体的模型能力下降。
- 卖家处理时长历史只聚合阶段时间有效的订单；无效阶段订单仍可贡献当时已知的 A/L 标签。
- 常数模型没有排序能力。其容量基准改为明确的随机种子抽样；期望精确率为测试延误率，
  一次抽样的实测值可以上下波动。分组容量结果注明是组内重新选取，并非全局队列的组别效果。
- 再校准可以使用测试前独立、已获得标签的校准集；报告不再声称必须用最终测试标签。
  校准偏差与漂移相容，但漂移的因果解释未得到检验。

## 结果和解释

见 `outputs/stage3_model_report.md`。要点：

- 逻辑回归在 dev 和 test 上都优于梯度提升；test 上 AP 差值的置信区间不含 0。
- 本轮逻辑回归 test AP=0.12346、ROC AUC=0.76093。每购买周前 10% 共选 1,986 单、捕捉 259 个延误，
  精确率 13.04%、召回率 30.47%；测试延误率 4.26%。随机抽样的期望精确率是 4.26%。
- 梯度提升 AP=0.11139。配对周 bootstrap 的 AP 差值区间（GBM−LR）约 [-0.02072,-0.00370]，
  条件于固定模型和这批购买周。该区间不包含模型重拟合不确定性，也未消除跨周序列相关。
- 两个模型的预测风险均值高于观察延误率，校准分箱也显示过预测。排序指标可作为本次离线基准；
  概率值尚不支持运营阈值决策。
- 去掉 `estimated_days` 后 AP 大幅下降：模型能力很大一部分依赖"存储的预计日期就是下单时展示的日期"这一未经核实的假设。
- 严格的标签规则会排除截止日前尚未签收的订单，而这部分订单延误比例高。这是不使用未来信息的代价，报告里有量化。

## 门禁与测试

- 阶段 3 只在阶段 1 为 READY、且源文件哈希未变时运行。失败标记写在 `outputs/stage3/qa/`，不影响阶段 1、2 的状态。
- 重跑阶段 1 会撤下阶段 2 和阶段 3 的当前报告。
- 9 项阻断检查通过；本轮共 57 项测试通过，包括未来验证标签不得进入模型选择和异常阶段历史过滤。
- `scripts/verify_stage3.py` 不导入项目计算模块：直接从原始订单与商品 CSV 复核人口和验证标签，
  对保存的预测独立计算 AP、秩统计 ROC AUC、Brier 和周容量命中数，所有结果一致。
- `outputs/stage3/lineage.json` 记录本轮配置/集市指纹、模型参数、选择截止时间及真实运行环境。
  本轮 Python 3.12.14、pandas 2.3.3、NumPy 2.5.1、scikit-learn 1.9.0；存在已记录的 DeprecationWarning。
