  S1. Model selection on validation data (F0 → V)
  Metric: pinball loss at q = 0.90 on the unshifted integer promise max{1, ⌈ŷ⌉}. A linear step
  was adopted only if it lowered the loss by at least 1%. Candidates within 1.001 × the global
  minimum counted as tied; inside a tie the simpler setting won.


     Candidate                              V loss          Change vs    Decision
                                                          current best

     C0 registered linear (log1p target,   1.28856                  —    start
     numeric weekday, no penalty)

     C1 weekday as a category              1.29170            −0.24%     rejected

     C2 raw-days target                    1.28932            −0.06%     rejected

     C3 L1 penalty, best of 3 alphas       1.28713             +0.11%    rejected (< 1%)
     (0.0001)

     D3 HGB, depth 2, 400 iterations       1.26266                  —    selected; tie set D3,
     (best of 8)                                                         D4, D7


  Post-hoc intervals on V. A week-block bootstrap on V (14 weeks, 2,000 draws) gives an
  improvement over C0 of 0.11% (−0.002% to 0.245%) for the C3 pick and 2.01% (1.11% to
  2.85%) for D3. The first interval shows no improvement reaching the pre-set 1% bar, so
  the original choice stands. Both candidates were picked on this same V, and the intervals
  do not include selection or refitting uncertainty; therefore D3's figure is optimistic and
  was only a reason to evaluate it.

  S2. A small simulation of two calibration failures (synthetic data)
  Question: does a calibration shift fail because the delivery distribution changes over time,
  or because at the freeze only the fast, already-delivered orders can be used? Delivery
  days follow log Y = 2.2 + 0.5x + 0.45ε, rounded up. The predictor is the conditional median,
  and the calibration code is the project's. Each of 1,000 replications draws 2,000 calibration
  and 5,000 evaluation orders (seed 20261021). All scenarios share the evaluation sample.
  For the time-change scenarios, the continuous delivery time is rescaled before rounding.


     Scenario minus the stable,       Coverage change, pts     Middle 90% of          Promised days
     complete-label scenario          (mean ± MC s.e.)         replications                 change

     Only delivered-by-freeze         −1.68 ± 0.015            −2.48 to −0.94                 −0.99
     labels (90-day window)

     Random subset of the same        +0.02 ± 0.009            −0.42 to +0.46                +0.02
     size (diagnostic)

     Later deliveries 15% slower      −5.77 ± 0.014            −6.50 to −5.08                      0

     Later deliveries 15% faster      +4.26 ± 0.012            +3.66 to +4.90                      0


  The two mechanisms leave different traces. Selective labels shrink the shift itself, so
  promised days and coverage fall together; a random subset of the same size does not. A
  later change in delivery times leaves the promise unchanged and moves only coverage.
  The "middle 90%" column is the spread of replications, not a confidence interval for the
  mean. A first, unpaired run (seed 20261020) gave the same picture. This explains
  mechanisms; it does not show which one, if either, acted in the Olist data.
